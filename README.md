# نیم‌فاصله‌یار

افزونه‌ی کروم برای اصلاح خودکار متن فارسی: نیم‌فاصله، حروف عربی، اعداد و نشانه‌گذاری — کاملاً لوکال، بدون هیچ ارتباط شبکه‌ای.

## امکانات

- **پاپ‌آپ اصلاح متن:** متن را بنویسید یا بچسبانید؛ اصلاح به‌صورت زنده انجام می‌شود و نتیجه را کپی کنید. `Ctrl+Enter` اصلاح و کپی را با هم انجام می‌دهد و متن ناتمام شما برای بازدید بعدی ذخیره می‌شود.
- **منوی راست‌کلیک:** روی هر فیلد متنی قابل ویرایش در هر صفحه، گزینه‌ی «اصلاح متن فارسی در این فیلد» متن همان فیلد را درجا اصلاح می‌کند.
- **۵ دسته‌ی اصلاح** با کلید روشن/خاموش که تنظیماتشان ذخیره می‌شود:
  1. حروف عربی: `ي ك ة ؤ ئ أ إ` ← `ی ک ه و ی ا ا` (آ دست نمی‌خورد)
  2. اعداد عربی: `٠١٢٣٤٥٦٧٨٩` ← `۰۱۲۳۴۵۶۷۸۹`
  3. نیم‌فاصله: `می شود` ← `می‌شود`، `کتاب ها` ← `کتاب‌ها`، `کتاب های من` ← `کتاب‌های من`، `بزرگ تر` ← `بزرگ‌تر`، `خانه ی من` ← `خانه‌ی من`، `خانه ام` ← `خانه‌ام`
  4. نشانه‌گذاری: حذف فاصله قبل از `؟ ، .` و…، یک فاصله بعد از نشانه‌ها، `« متن »` ← `«متن»`، `...` ← `…`، جمع‌کردن فاصله‌های اضافه و سطرهای خالی
  5. اعداد لاتین (اختیاری، پیش‌فرض خاموش): `123` ← `۱۲۳`
- **آمار اصلاح:** تعداد کل اصلاحات + تفکیک هر دسته.
- **حالت تیره/روشن** با ذخیره‌ی انتخاب شما.
- فونت وزیرمتن به‌صورت داخلی همراه افزونه است؛ هیچ فونتی از اینترنت خوانده نمی‌شود.

## حریم خصوصی

۱۰۰٪ لوکال. متن شما هرگز از مرورگر خارج نمی‌شود؛ هیچ درخواستی به هیچ سروری فرستاده نمی‌شود. افزونه فقط به `storage` (ذخیره‌ی تنظیمات)، `contextMenus` (منوی راست‌کلیک) و `activeTab` + `scripting` (اصلاح فیلد صفحه‌ی فعلی، فقط وقتی خودتان از منو انتخاب می‌کنید) دسترسی دارد. هیچ `host_permissions` و هیچ `content_scripts` دائمی وجود ندارد.

## محدودیت‌های شناخته‌شده

- در فیلدهای `contenteditable` (ویرایشگرهای غنی مثل ویرایشگر بعضی سایت‌ها)، اصلاح روی متن ساده انجام می‌شود و قالب‌بندی داخلی (پررنگ، لینک و…) از بین می‌رود.
- قوانین نیم‌فاصله مبتنی بر الگوهای رایج‌اند؛ متن‌های خیلی خاص یا ادبی ممکن است نیاز به بازبینی دستی داشته باشند.
- «را» و حروف اضافه (`به`، `از`، `در`، `با`) عمداً جدا می‌مانند و افعال مرکب (`تمیز کردن`) به هم نمی‌چسبند.
- «ها»ی تأکیدی محاوره‌ای (`برو ها!`) از «ها»ی جمع قابل تشخیص نیست و ممکن است به کلمه‌ی قبل بچسبد؛ متن‌های محاوره‌ای را بعد از اصلاح یک نگاه بیندازید.
- دامنه‌ها و ایمیل‌های لاتین (`site.com`) و مخفف‌های لاتین (`U.S.A`) عمداً دست نمی‌خورند.

## توسعه

```sh
node tests/fixer.test.js   # تست موتور اصلاح (۶۳ مورد، بدون وابستگی)
```

ساختار فایل‌ها:

| فایل | توضیح |
| --- | --- |
| `manifest.json` | مانیفست نسخه ۳ |
| `fixer.js` | موتور قوانین (UMD: هم در مرورگر، هم در Node) |
| `popup.html` / `popup.css` / `popup.js` | رابط پاپ‌آپ |
| `background.js` | سرویس‌ورکر + منوی راست‌کلیک |
| `inject.js` | اصلاح فیلد صفحه‌ی فعلی |
| `tests/fixer.test.js` | تست‌ها |
| `fonts/` | وزیرمتن (داخلی) |
| `icons/` | آیکون‌های ۱۶/۴۸/۱۲۸ |

## English summary

NimFaselehYar is a local-only Chrome extension (Manifest V3) that fixes Persian text: ZWNJ half-spaces (`می شود` → `می‌شود`), Arabic letters/digits → Persian ones, punctuation spacing, and optional Latin→Persian digits. It offers a popup fixer and a right-click "fix this field" action for any editable field. No network calls, no host permissions, no persistent content scripts. Settings persist via `chrome.storage`. Tests: `node tests/fixer.test.js`.
